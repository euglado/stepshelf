# Contributing / Katkı

Please describe the problem and intended behavior in an issue before a large change. For a small fix, send a pull request with reproduction steps and relevant tests. Use Node.js 24, `npm ci --ignore-scripts`, `npm run check` and `npm audit --audit-level=low`. `npm run format` fixes formatting. Never add tokens, private server content or `.env`. Maintain Turkish and English UI/documentation, minimal permissions, private previews and user-bound readers. Tests use synthetic interactions; do not require live tokens in CI.

Büyük değişiklikten önce sorunu ve beklenen davranışı bir issue ile açıklayın. Küçük düzeltmeler için yeniden üretme adımlarını ve ilgili testleri içeren pull request açın. Node.js 24 ile yukarıdaki komutları çalıştırın. Türkçe/İngilizce metinleri, düşük izinleri, özel önizlemeyi ve kullanıcıya bağlı okuyucuları koruyun. Token, özel sunucu içeriği veya `.env` eklemeyin; CI için canlı Discord kimlik bilgisi istemeyin.
