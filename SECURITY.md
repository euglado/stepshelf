# Security / Güvenlik

Do not put tokens, personal data or sensitive guide text in a public issue. For an exposed token, immediately reset it in Discord Developer Portal → Bot, then replace your local `.env` using setup and restart. Removing a commit is not enough. For a vulnerability, use this repository's private GitHub vulnerability reporting if enabled; otherwise contact the repository owner through an available private channel before publishing details. This project has no guaranteed response time or hosted support service.

Public issue içine token, kişisel veri veya hassas rehber metni koymayın. Açığa çıkan tokenı hemen Developer Portal → Bot üzerinden sıfırlayın; yerel `.env` dosyasını kurulumla yenileyip botu yeniden başlatın. Commit silmek yeterli değildir. Güvenlik açığı için varsa GitHub özel güvenlik bildirimi kullanın; yoksa ayrıntıları yayımlamadan depo sahibine mevcut özel bir kanaldan ulaşın. Yanıt süresi veya barındırılan destek hizmeti garantisi yoktur.
